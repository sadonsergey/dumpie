Already using spatie/ray?

Keep your ray() calls, skip the paid desktop app

Dumpie speaks the same protocol and listens on the same port, 23517. Projects with spatie/ray or spatie/laravel-ray send their output to PhpStorm as they are: no code changes, no extra package, no license to buy.

Free and open source, right next to your code.

ray($order)->green();
ray()->showQueries();
ray()->measure();
ray()->pause();
  • Tables, queries, events, jobs, mails, models, exceptions, measure(), pause(), colors, labels and screens
  • Plus what only an IDE can do: gutter icons on the lines that sent output, links that open the file, a session per project
  • Both apps use port 23517: quit the desktop app, or give Dumpie its own port and move projects one at a time

Everything your PHP app prints, where you write it

No separate app, no extra browser tab, no scrolling through laravel.log. Dumpie catches output from Symfony VarDumper, your log files and the spatie/ray protocol.

From the code to its output

Lines that sent output get an icon in the editor gutter. Hover it to see what they sent, click it to jump to the entry. And the other way round: every entry links to its file and line, Docker and Sail paths included.

SQL insights

Queries that run again and again with different values are marked Repeated, a classic N+1. Slow ones are marked Slow, and the toolbar shows how many queries a screen ran and their total time.

Exceptions and logs you can read

Highlighted code around the failing line, folded vendor frames, log levels as colors. Filter by color or text, pause the feed, collapse what you have seen.

Copy a dump as working PHP code

Every dump, query and JSON block has its own copy button. A dump turns into a PHP array you can paste straight into a test or a seeder; an object becomes an array of its properties. Queries copy as SQL with the values in place, ready to run.

Need the whole entry? Copy it as plain text or as Markdown with highlighted code blocks, without file names in the way.

Every color counts in the filter

Whatever shows up in a color is found by that color: ray()->red(), log levels, exceptions, slow queries in red and repeated ones in orange. Plain dumps and info records sit under gray, so one click hides them or shows only them.

See where dd() stopped the script

The last dump of a dd() is marked Script stopped here, so a missing entry after it is no mystery. rd() and ray()->die() get the same mark.

Errors do not slip by

Keep the tool window hidden while you work: when an exception or an error log record arrives, its icon gets a red mark with the number of new errors in the tooltip. Open it and the last error is already in view.

Many projects, nothing mixes up

A session per project with unread counters. Open any project's session from any window, or see all of them in one feed, tagged by project.

Several IDEs at once

PhpStorm and WebStorm side by side, or two IDE versions? Output of every project reaches the window that has it open, and ray()->pause() can be continued from either.

Open any entry in the editor

Big dumps, JSON and SQL open in an editor tab next to your code, with the IDE's highlighting, search and folding.

At home in a narrow tool window

Squeeze the tool window next to your code: the toolbar wraps instead of hiding buttons, the color filters first, then the counters, everything on one left edge. Every icon explains itself in a tooltip.

Small things that add up

Built for reading a lot of output quickly, and for not losing any of it.

Nothing lost

Whatever Clear removes goes to an archive and can be restored to the project it came from.

Screens

ray()->newScreen() or ⌘N starts a fresh screen; earlier ones stay one click away.

Copy text or Markdown

Any entry goes to the clipboard as plain text or as fenced code blocks that keep highlighting in chats and issues.

Follows your IDE

Light and dark themes, fonts, syntax colors and the time format come from the IDE.

Guided setup

An empty tool window shows what a project is missing, with an Add to .env button.

Local only

Dumpie listens on 127.0.0.1. Nothing leaves your machine.

Quick start

Works with any project that has symfony/var-dumper, which comes with Laravel and Symfony.

Install the plugin

Settings › Plugins › Marketplace, search for Dumpie and press Install. Or install it from JetBrains Marketplace.

Add one line to .env

Or press Add to .env in the Dumpie tool window.

VAR_DUMPER_FORMAT=server

Dump something

It shows up in the tool window instead of the page. Projects with spatie/ray need no setup at all.

dump($order);

No access to the Marketplace? Download the zip from Releases and use Settings › Plugins › ⚙ › Install Plugin from Disk…

Keyboard first

The shortcuts work in the Dumpie tool window and can be remapped in Settings | Keymap. The editor keeps its own: ⌘K still commits there. Ctrl instead of ⌘ on Windows and Linux. An empty tool window lists them, remapped ones included, until they become a habit.

Settings

Settings | Tools | Dumpie. Receivers, display and SQL options apply to every project, the last group to the open project only. Apply takes effect at once, no restart needed.

DisplayAll projects

Show the tool window on outputOn

Opens Dumpie when something arrives. Turn it off to stay in the flow and rely on the error mark.

Pinned project and screen barsOn

Off lets the bars scroll away with the feed for more room.

White background in light themesOn

The feed matches the editor instead of the tool window gray.

Gutter iconsOn

Marks the lines that sent output. Hover to preview, click to jump to the entry.

Error mark on the iconOn

Exceptions and error logs while the window is hidden. Opening it scrolls to the last error.

Entries without a color are grayOn

The gray dot also finds plain dumps, info logs and ray() without a color.

ReceiversAll projects

spatie/ray clients23517

Receives ray() over HTTP. If another app holds the port, pick another one and set RAY_PORT in the project.

dump() / dd() server9912

Receives VarDumper dumps. The project sends them with VAR_DUMPER_FORMAT=server and VAR_DUMPER_SERVER.

Both listen on 127.0.0.1 only. A busy port is retried every 5 seconds.

This projectOpen project

ray() outputOn

Shows this project's ray() calls and whether spatie/ray is in composer.lock.

dump() outputDetected

On when symfony/var-dumper is installed. Add to .env writes the two lines it needs, host.docker.internal for Sail.

Log filesDetected

Follows Monolog logs in storage/logs or var/log: new records only, colored by level.

Log file patterns*.log

Globs relative to the project root, one per line, wildcards in the file name only.

Detect Again

Reads composer.lock, .env and the log directories again.

Filled in when the project is opened for the first time; your changes are kept after that.

SQL queriesAll projects

Query totals in the toolbarOn

Count and total time of the screen, orange when something needs a look.

Repeated queriesOn

The same statement with other values 3 or more times on one screen: a likely N+1.

Slow queries100 ms

Anything slower is marked Slow and found by the red filter.
